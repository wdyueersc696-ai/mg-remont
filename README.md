# MG Ремонт

Сайт Максима Гуревича: ремонт квартир и загородных домов в Москве и Московской области.

## Запуск

```powershell
npm run dev -- --host 127.0.0.1
```

Откройте адрес Local из терминала. Проверка типов: `npx tsc --noEmit`.

Для сборки в текущем окружении Sites:

```powershell
node 'C:\Users\ikrit\.codex\plugins\cache\openai-curated-remote\sites\1.1.4\scripts\build-site.mjs'
```

## GitHub Pages и Sites

Один и тот же `app/page.tsx`, компоненты и CSS используются для двух площадок. Основные команды `dev`, `build` и `start`, файл `vite.config.ts` и конфигурация `.openai/` сохраняют сборку Sites. Для GitHub Pages добавлена отдельная статическая сборка без Worker, авторизации Sites и серверных API.

После чистого клонирования установите зависимости на Node.js 22.13 или новее:

```powershell
npm run install:ci
```

Собрать и проверить версию GitHub Pages:

```powershell
npm run build:pages
npm run preview:pages
```

Локальный адрес: http://127.0.0.1:4173/mg-remont/. После публикации адрес сайта — https://wdyueersc696-ai.github.io/mg-remont/.

- `vite.pages.config.ts`: отдельный Vite/React config, `base: "/mg-remont/"`, результат в `dist-pages/`.
- `github-pages/main.tsx`: подключает существующую страницу и стили; отдельной копии интерфейса нет.
- `github-pages/index.html`: метаданные и canonical для GitHub Pages. Метаданные Sites остаются в `app/layout.tsx`.
- В этой сборке строковые пути `/media/…` из TS/TSX автоматически получают префикс `/mg-remont/`. CSS `url()` и HTML-ассеты обрабатывает Vite. Исходники страницы сохраняют пути, совместимые с Sites.
- Для публикации из ветки `gh-pages` в её корне должны лежать **содержимое** `dist-pages/`, включая `index.html`, `.nojekyll`, `assets/`, `media/` и `fonts/`. Не помещайте их внутрь дополнительной папки `dist-pages`. Готовая сборка не требует Node.js или CI на стороне GitHub Pages.
- В `main` хранятся исходники; `dist-pages/` исключён из Git. После изменения страницы или медиа пересоберите Pages и обновите ветку публикации. Изменение имени репозитория требует обновить `base`, canonical и Open Graph URL.

## Где редактировать

- `app/page.tsx`: тексты, проекты, ссылки и поведение.
- `app/globals.css`: оформление и адаптивные версии.
- `app/layout.tsx`: название, описание и метаданные.
- `public/media/`: локальные фотографии и видео.
- `public/media/SOURCES.md`: происхождение материалов и статусы объектов.
- `.openai/hosting.json`: существующий Site ID; не создавать новый Site для следующих правок.

## Согласованные решения

Бренд: MG Ремонт. Кнопки Telegram пока ведут в публичный канал https://t.me/maximgurevich, по выбору пользователя. Для перехода к личным заявкам нужно заменить константу TELEGRAM на подтверждённый личный контакт.

Визуальный референс: https://iventions.com/. Воссозданы светлый первый экран с лавандовыми лучами, раскрытие медиа при скролле на компьютере и телефоне, крупная типографика, диагональное меню, полноэкранные проекты, пастельные секции и контактная сцена. Для кириллицы используется Onest вместо Soehne, Georgia вместо ABCArizonaMix. Лицензия Onest лежит в public/fonts/OFL.txt.

Дом 210 м² показан как завершённый интерьер. Квартира 73 м² в районе ЗИЛ показана в работе; её иллюстрация явно подписана как ИИ-концепция, а не фотография готового объекта. Отзывы, стаж, цены и гарантии не выдуманы. Отдельные интерьерные кадры в блоках направлений относятся к одному и тому же дому, а не к дополнительным кейсам.

## Медиа и доступность

Медиа размещены локально; временные ссылки CDN соцсетей не требуются для просмотра. Полные обзоры и фотографии открываются по действию посетителя в диалоге. Меню и просмотр медиа закрываются клавишей Escape. Полноэкранное увеличение первого экрана при прокрутке работает на компьютере и мобильном устройстве. При `prefers-reduced-motion` скролл-анимации отключаются, а сцена цифр превращается в обычные карточки.
